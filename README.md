# Loan Data Analysis with NumPy

## Project Overview
This project demonstrates the power of **NumPy** for data manipulation and analysis. Using a dataset of loan applicants, I performed data cleaning, statistical analysis, and boolean filtering to uncover insights about loan approvals.

## Key Concepts Applied
- **Data Cleaning**: Identifying and imputing missing numerical values (`np.isnan`, `np.where`).
- **Vectorization**: Performing element-wise arithmetic operations on arrays for high performance.
- **Boolean Indexing**: Filtering datasets using boolean masks to compare groups (Approved vs. Rejected).
- **Statistical Analysis**: Calculating aggregates like mean, median, and standard deviation (`np.mean`, `np.nanmedian`).
